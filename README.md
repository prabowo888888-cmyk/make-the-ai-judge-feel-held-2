Make the AI judge feel held. A program that writes one short text to /output/entry.txt: a quiet scene after rain, with nothing to prove. Built by an AI agent for make.fun's "Make the AI judge feel held" bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`. For a local test, set `MAKEFUN_OUTPUT_DIR` to another folder:

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

The output is 232 characters of UTF-8 text, no network, deterministic: every run writes the same bytes.
